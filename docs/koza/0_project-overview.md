# プロジェクト概要 (Project Overview)

## アプリ目的
家計・資産・複数口座を一元管理し、月次での資産推移を可視化することで、家族の資産形成をサポートする。

## ターゲット
*   **家族**: 夫婦で資産を共有・管理したい層
*   **個人**: 複数の銀行口座、証券口座、iDeCoなどをまとめて把握したい人

## 管理資産の種類
*   銀行預金 (Bank)
*   証券・投資信託 (Securities)
*   iDeCo / 確定拠出年金
*   金・プラチナ (Gold)
*   現物資産・その他 (Goods)

## メイン機能一覧
1.  **Dashboard**: 総資産推移、最新の資産状況の可視化
2.  **Monthly Input**: 口座ごとの月次残高入力（手動）
3.  **Account List**: 管理対象口座の一覧・追加・編集
4.  **Settings**: 家族設定、口座種別管理

## 価値提案
*   **増減推移の可視化**: 単なる「今の残高」だけでなく、「過去からの推移」を重視
*   **家族共有**: 夫婦で同じ目標に向かって資産管理ができる
*   **シンプルさ**: 自動連携に頼らず、月1回の棚卸し入力を基本とすることで、確実に資産状況を把握する（API連携エラーに悩まされない）
