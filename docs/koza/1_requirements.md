# 要件定義 (Requirements)

## 機能要件
1.  **口座管理**
    *   口座の登録、編集、削除
    *   口座種別（銀行、証券、iDeCoなど）の設定
    *   所有者（夫、妻、共通など）の割り当て
2.  **月次残高記録**
    *   年月を指定して、各口座の残高を入力できる
    *   前月の残高をコピーして入力補助とする機能
    *   メモ書き（「ボーナス入金」「旅行で出費」など）の保存
3.  **可視化（Dashboard）**
    *   総資産の月次推移グラフ
    *   アセットアロケーション（種別ごとの割合）円グラフ
    *   前月比、前年比の表示
4.  **設定**
    *   家族メンバーの追加・編集
    *   表示通貨（基本は円）

## 非機能要件
1.  **UI/UX**
    *   **家族向けデザイン**: 落ち着いた色味（グリーン/ネイビー/ベージュ）
    *   **入力のしやすさ**: Tabキーでの移動、数値入力のスムーズさ
    *   **レスポンシブ**: PCでの管理を主とするが、スマホでの閲覧も考慮
2.  **操作性**
    *   一覧性が高く、全体像を把握しやすい画面構成
3.  **セキュリティ**
    *   家族単位でのデータ分離（今回はモックだが将来的にはRLS）

## 分析軸
*   **口座別**: 特定の口座の推移
*   **人別**: 夫・妻・共通ごとの資産額
*   **月別**: 特定月の資産状況
*   **年別**: 年単位での増減

## 月次入力ルール
*   原則、月末時点の残高を入力する運用
*   入力はいつでも修正可能
*   未入力月はグラフ上では前月維持または線形で補間（表示ロジックで対応）

## 前月コピー仕様
*   「前月コピー」ボタン押下で、直近の入力済み月のデータを当該月にコピーする（値は微調整して保存）

## メモ記録
*   Balanceモデルに `memo` フィールドを用意し、定性的な情報を残せるようにする
