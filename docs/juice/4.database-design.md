# Juice - データベース設計（想定）

Phase 1ではUI実装を優先し、データはモックまたはLocalStorageを利用しますが、
データ構造を明確にするために定義します。

## 1. エンティティ

### Users (Player)
対戦に参加するプレイヤー。
- id: string (UUID)
- name: string (表示名)
- avatar: string (アイコン)
- color: string (テーマカラー)

### Games (Match/Event)
対戦のイベントそのもの。
- id: string
- title: string (例: "週末フットサル")
- date: timestamp

### Wagers (Ogo-ri)
「誰が誰に何を」の記録。
- id: string
- game_id: string (Games.id)
- from_user_id: string (敗者/おごる人)
- to_user_id: string (勝者/もらう人)
- item_name: string (例: "コーラ", "ランチ")
- quantity: number (例: 1, 2)
- unit: string (例: "本", "円")
- status: string (pending:未精算, settled:精算済み)

## 2. 状態管理 (Client State)

UI実装フェーズでは、以下の状態を管理します。

```typescript
type Player = {
  id: string;
  name: string;
};

type Log = {
  id: string;
  date: string;
  winnerId: string;
  loserId: string;
  item: string;
  amount: number;
};

// ダッシュボード用集計データ
type Summary = {
  playerId: string;
  totalWon: number; // おごってもらえる総数
  totalLost: number; // おごる総数
  balance: number; // 収支
};
```
