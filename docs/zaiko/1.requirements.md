# **1. アプリ概要（詳細版）**

**「家庭在庫の管理を“考える手間ゼロ”へ」**

家庭で使う全ストック品（トイレ紙、洗剤、ラップ、調味料、ティッシュ、オムツなど）を、
**スマホ1つでラクに登録・補充・共有できる在庫管理アプリ。**

ポイントは以下：

* **初回登録 → あとは在庫が減った時だけメンテ**
* **家族で同じ在庫情報をリアルタイム共有**
* **買い物中に“買うべきものが一目でわかる”UI**
* **通知で在庫切れを確実に回避**
* **スマホネイティブアプリ同等の体験（アニメーション多数）**

→ 「コンサルのように効率を求める人」がターゲットとなる“細部まで快適”な操作設計。

# **2. ターゲット・利用シーン（大幅に深堀り）**

## **2.1 ターゲット層**

* 家族で暮らす社会人（忙しい・土日まとめ買い）
* 夫婦で家事分担している層
* 1人暮らしの効率ガチ勢
* 共働き / 育児世帯
* 在宅ワーカー（家でのストック消費が多い）

## **2.2 ユーザー課題（Before）**

* トイレットペーパーなど**残量が曖昧で買い忘れる**
* 家族が勝手に開封しても**在庫の変動が共有されない**
* 買い物中に
  「柔軟剤まだあったっけ？」
  「洗剤減ってた気がするけど…？」
  と立ち止まる
* 在庫管理系アプリは**入力が面倒で続かない**

## **2.3 価値提供（After）**

* “残り◯個、買うべき”が一瞬でわかる
* 家族が更新するとリアルタイムで共有
* 入力しなくても、ボタン1つで“在庫＋1/-1”
* 在庫が少なくなったらアプリが自動で通知
* 買い物前にアプリを開けば一発で買うものがわかる

# **3. デザイン・UXコンセプト（超詳細）**

## **3.1 トーン & マナー**

* Apple純正アプリのような「余白」と「軽さ」
* Walicaのような柔らかい雰囲気も融合
* 角丸は**大きめ（16〜24px）**
* 影・ガラスモーフィズムは控えめ、アクセント程度

## **3.2 モバイル最適化**

* 基本UIは**iPhoneの幅（375px）で最適化**
* Thumb Zoneを意識して、

  * FAB
  * Bottom Sheet
    を右下・画面下部に配置

## **3.3 ダークモード & ライトモード**

* **基本方針**:
  * 設定ページからライトモード/ダークモードの切り替えが可能であること。
  * **Simpro本体との整合性**: ホワイトとグレーの色味（ベースカラー）はSimproおよび個別のアプリケーションで同様のものを使用する。差し色についてはアプリごとに異なるが、彩度や明度はSimproの基準に合わせることで統一感を出す。

* **カラー定義**:

  **◼︎ ライトモード**
  * メインカラー：ホワイト
  * サブカラー：グレー
  * 差し色：グリーン（Zaiko固有）

  **◼︎ ダークモード**
  * メインカラー：グレー
  * サブカラー：ホワイト
  * 差し色：グリーン（Zaiko固有）

## **3.4 アニメーション（LP含む重要部分）**

**「AI生成感を消した、人間が作ったような手触り」**

* フェード + スライドの自然挙動
* Gravity（慣性）を少し効かせる（Bottom Sheet）
* アイコンが0.2秒でゆっくり拡大 → 定位置で止まる
* スクロールに応じて要素がふわっと出る
* CTAボタンは押下時に0.92のスケールダウン → 戻る

**＝Webアプリなのに“ネイティブに感じる”動きを採用**

ポイントだけ整理する。

* `layout.tsx`
  Zaiko専用の画面枠。スマホライクなコンテナ。ヘッダー読み込み。背景色。テーマ適用。
* `page.tsx`
  LP。セクション分割。アニメーション多め。
* `dashboard/` 以下
  在庫一覧のメイン画面。`_components/inventory/*` を多用。
* `_components`
  画面単位でなく**役割単位**で分割。
  layout / inventory / common にまとめる。
* `_hooks`
  状態管理とサーバー呼び出しを集約。
  画面ではロジックを薄くする。
* `_lib`
  定数やZodスキーマ、アニメーションプリセット置き場。

## 2. Shadcn + Tailwind + Framer Motion 前提のコンポーネント設計

### 2.1 レイアウト系

#### `layout/zaiko-shell.tsx`

* 役割

  * 全画面共通の枠
  * ヘッダー + コンテンツ + 下部余白
* 主な技術

  * Shadcn `ScrollArea`
  * Tailwind `max-w-[430px] mx-auto px-4` など
* Props

  * `children`
* 振る舞い

  * 背景にグラデーション
  * スマホ中央に白いカード風コンテナ配置

#### `layout/zaiko-header.tsx`

* 役割

  * 画面上部ヘッダー
* UI

  * 左：アイコン
  * 中央：タイトル
  * 右：ハンバーガーメニュー or ボタン
* 主なShadcn

  * `Button` (icon button)
  * `Sheet` or `Drawer`（ハンバーガーメニュー用）
* 挙動

  * ハンバーガー押下で `zaiko-bottom-sheet` 呼び出し
  * スクロール時に軽く影を表示

#### `layout/zaiko-bottom-sheet.tsx`

* 役割

  * 下からスライドするメニュー / クイック編集
* 技術

  * Radix `Sheet` ベースの Shadcn `Sheet`
  * Framer Motion でバウンド感付与
* Props

  * `open`
  * `onOpenChange`
  * `title`
  * `children`

#### `layout/fab-add-button.tsx`

* 役割

  * 右下の + FAB
* 技術

  * Shadcn `Button`（丸）
  * Framer Motion `whileTap={{ scale: 0.9 }}`
* Props

  * `onClick`
  * `icon` 差し替え可

### 2.2 在庫表示系

#### `inventory/inventory-card.tsx`

* 役割

  * ダッシュボードの1アイテムカード
* 構造

  * 左：アイコン（丸背景）
  * 中央：

    * アイテム名
    * 残量 / 場所
  * 右：

    * ステータスバッジ
    * 「…」ボタン
* 技術

  * Shadcn `Card`, `Badge`, `DropdownMenu`(or bottom sheet トリガ)
  * Framer Motion `motion.li` で表示アニメ
* Props

  ```ts
  type InventoryStatus = "enough" | "low" | "empty";

  type InventoryCardProps = {
    name: string;
    quantity: number;
    location?: string;
    status: InventoryStatus;
    iconName: string;
    onClick: () => void;
    onQuickEdit: () => void;
  };
  ```

#### `inventory/inventory-list.tsx`

* 役割

  * `inventory-card` を並べるリスト
* 技術

  * `AnimatePresence` で追加・削除アニメ
* Props

  * `items: InventoryCardProps[]`
  * `isLoading`

#### `inventory/inventory-filter-chips.tsx`

* 役割

  * カテゴリ切り替えチップ
* 技術

  * Shadcn `ToggleGroup` or `Badge` + button
* Props

  ```ts
  type FilterChipsProps = {
    filters: { id: string; label: string }[];
    activeId: string;
    onChange: (id: string) => void;
  };
  ```

#### `inventory/inventory-detail-form.tsx`

* 役割

  * 詳細 / 新規登録フォーム本体
* 技術

  * Shadcn `Form`, `Input`, `Select`, `Textarea`, `NumberInput 相当`
  * Zod + React Hook Form
* 項目

  * 名称
  * アイコン
  * カテゴリ
  * 場所
  * 数量
  * 閾値
  * メモ

#### `inventory/inventory-quantity-stepper.tsx`

* 役割

  * 数量の + / - 操作
* 技術

  * `Button` 2つ + 中央に数字
  * Framer Motion `animate` で数字フェード
* Props

  ```ts
  type QuantityStepperProps = {
    value: number;
    min?: number;
    max?: number;
    onChange: (value: number) => void;
  };
  ```
