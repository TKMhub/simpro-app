# Zaiko プロジェクト管理

Zaikoアプリの開発タスク、進捗、ロードマップを管理します。

## 1. ロードマップ
開発プロセス（`docs/project-rules.md`）に基づき、以下の順序で進行します。

- **Phase 1: UI/UX 実装** (画面のガワ作成)
- **Phase 2: バックエンド構築** (DBスキーマ・モデル)
- **Phase 3: API & ロジック実装** (データ連携)
- **Phase 4: 機能拡張 & テスト** (通知・共有・仕上げ)

## 2. タスク一覧
